1. Objetivo de la auditoría

Esta auditoría documenta el uso de ChatGPT como herramienta de inteligencia artificial generativa durante el desarrollo de VitrinaSur.

Su objetivo es identificar los ámbitos en los que se utilizó asistencia de IA, los problemas abordados, las soluciones propuestas y las pruebas realizadas para verificar los resultados.

2. Herramienta utilizada

Herramienta: ChatGPT, de OpenAI.

Uso: asistencia en programación, depuración, integración, diseño, documentación y explicación de conceptos técnicos.

La herramienta se utilizó como apoyo al desarrollo, no como sustituto de las pruebas de funcionamiento ni de la revisión del código.

3. Casos de uso y validación

Caso 1 — Navegación React Router

Problema: algunas rutas no funcionaban y se presentó un error por utilizar Route fuera de Routes.

Asistencia de IA: revisión de la configuración de React Router y propuestas de corrección.

Validación: se realizaron pruebas de navegación SPA, acceso a productos, productores, categorías y detalle de productos.

Caso 2 — Integración frontend y backend

Problema: inicialmente algunas vistas utilizaban datos locales y no consultaban la API.

Asistencia de IA: orientación para crear funciones de consulta y conectar componentes React con endpoints Express.

Validación: se comprobaron respuestas JSON de productos, productores y categorías.

Caso 3 — PostgreSQL

Problema: dificultades de instalación, autenticación, conexión y configuración de variables.

Asistencia de IA: interpretación de errores de PostgreSQL, orientación sobre psql y configuración del backend.

Validación: se comprobó la conexión local y la existencia de cinco tablas: usuarios, productos, productores, categorías y prepedidos.

Caso 4 — Autenticación y autorización

Problema: necesidad de implementar registro, inicio de sesión, cierre de sesión y restricciones de acceso.

Asistencia de IA: revisión de middleware JWT, gestión de cookies, contexto de autenticación y roles.

Validación: se probaron respuestas HTTP de autenticación, autorización y funcionamiento de la sesión.

Caso 5 — Diseño responsivo

Problema: errores de alineación, contraste de títulos, botones y menú móvil.

Asistencia de IA: propuestas de cambios CSS y revisión de componentes.

Validación: se realizaron pruebas en vistas móviles, tablet y escritorio, manteniendo el diseño visual de VitrinaSur.

Caso 6 — Compilación y despliegue

Problema: errores de importación por diferencias entre mayúsculas y minúsculas en nombres de archivos CSS.

Asistencia de IA: diagnóstico de errores de compilación y revisión de rutas de importación.

Validación: se ejecutó npm run build correctamente y se publicó el proyecto.

5. Riesgos y limitaciones de la IA

  • Las respuestas generadas pueden contener código incorrecto o incompleto.
  • Las recomendaciones pueden no coincidir con la estructura real del proyecto.
  • Una solución funcional localmente puede fallar en producción.
  • Las configuraciones de seguridad requieren revisión adicional.
  • No deben compartirse contraseñas, tokens ni archivos de entorno privados.

Para reducir estos riesgos se utilizaron pruebas de compilación, consultas HTTP, revisión de consola, comprobaciones SQL y pruebas de interfaz.

6. Responsabilidad y validación humana

La IA generativa se utilizó como herramienta de apoyo técnico. Las modificaciones al proyecto fueron aplicadas y comprobadas durante el proceso de desarrollo.

La existencia de una sugerencia de IA no constituye evidencia suficiente de que una funcionalidad sea correcta. Se requiere comprobar el comportamiento del sistema y revisar los resultados.

7. Conclusiones

La utilización de ChatGPT permitió apoyar la resolución de problemas de navegación, integración, base de datos, autenticación, diseño responsivo y despliegue.

El proceso mostró la importancia de combinar asistencia de inteligencia artificial con revisión humana, pruebas técnicas y documentación verificable.
