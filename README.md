## 📌 1. Descripción del proyecto

VitrinaSur es una aplicación web full-stack diseñada para facilitar la visibilización y comercialización digital de productos y productores locales de Chiloé. El proyecto busca centralizar la oferta fragmentada de la isla en una plataforma moderna, rápida y fácil de usar, evitando ser un e-commerce genérico.

## 🎯 2. Problema identificado

Chiloé tiene una oferta amplia de productos, oficios, gastronomía, artesanía y producción local. Sin embargo, esta oferta está fragmentada, dispersa y tiene una baja digitalización comercial. VitrinaSur resuelve esto conectando directamente al productor con el comprador.

## 🚀 3. Objetivos

### Objetivo general
Presentar una vitrina digital territorial que conecte productores locales de Chiloé con compradores, facilitando la exploración de productos, el contacto y los prepedidos con retiro coordinado.

### Objetivos específicos
* Centralizar la exhibición de productos locales.
* Facilitar la exploración y navegación por el catálogo.
* Presentar información detallada de productos y productores.
* Incorporar un flujo de prepedido funcional.
* Mantener una identidad visual coherente y responsiva.
* Organizar el sistema mediante una arquitectura backend por capas.

## 🛍️ 4. Funcionalidades principales

| Módulo | Descripción |
| :--- | :--- |
| **Inicio** | Exploración de productos destacados, presentación de identidad visual y buscador. |
| **Catálogo** | Vista completa de productos con filtros por categoría. |
| **Detalle** | Información ampliada de cada producto, precio y datos del productor. |
| **Prepedido** | Formulario de contacto para coordinar el retiro con el productor (con validación). |
| **Backend API** | Servidor Node.js/Express conectado a PostgreSQL que provee los datos reales. |
